## File Structure

Each country directory contains:
- **multi-entity-service.json** - Company structures (parent companies and subsidiaries)
- **product-service.json** - Products and services offered (music, events, fashion, etc.)
- **customer-service.json** - Business customers (TV stations, brands, event organizers)
- **vendor-service.json** - Suppliers (equipment, production, marketing services)
- **current-user-context.json** - Current user/owner context
